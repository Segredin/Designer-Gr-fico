1. Introdução
O projeto Nossas Futuras Profissões foi desenvolvido com o objetivo de apresentar diferentes áreas profissionais que despertam o interesse dos integrantes do grupo. A plataforma reúne informações sobre carreiras como Programação, Desenvolvimento de Software, Desenvolvimento de Jogos, Design Gráfico, Gestão de Banco de Dados e Vôlei Profissional, demonstrando suas principais funções, áreas de atuação e importância no mercado de trabalho.
Além de apresentar essas profissões, o projeto também permitiu colocar em prática conhecimentos adquiridos durante o curso, utilizando tecnologias de desenvolvimento web para criar um site moderno, organizado e interativo.
2. Objetivo do Projeto
O principal objetivo do projeto é desenvolver uma plataforma informativa que permita ao usuário conhecer diferentes profissões e compreender suas características, responsabilidades e oportunidades de atuação.
Além disso, o projeto busca aplicar conceitos de desenvolvimento web, organização de conteúdo, design de interface e programação, promovendo o aprendizado prático dos integrantes.
3. Tecnologias Utilizadas
Durante o desenvolvimento foram utilizadas as seguintes tecnologias:
HTML5
CSS3
JavaScript
Git e GitHub
Figma (protótipos e planejamento)
Algumas áreas apresentadas no site também citam tecnologias utilizadas na profissão, como:
Python
Java
SQL
4. Estrutura do Sistema
O sistema foi desenvolvido como um site composto por diversas páginas, cada uma dedicada a uma profissão específica.
As páginas possuem:
Página Inicial
Login
Área de Programação
Desenvolvimento de Software
Desenvolvimento de Jogos
Design Gráfico
Gestão de Banco de Dados
Vôlei Profissional
A navegação foi planejada para ser simples e intuitiva, permitindo que o usuário explore facilmente cada profissão.
5. Funcionalidades
Entre as principais funcionalidades do projeto destacam-se:
Sistema de Login.
Navegação entre páginas.
Apresentação das profissões.
Interface responsiva e organizada.
Utilização de imagens ilustrativas.
Layout moderno.
Organização das informações por categoria.
6. Descrição das Páginas
Página Inicial
Apresenta uma introdução ao projeto e explica sua proposta, destacando a importância da tecnologia, criatividade, esporte e inovação no mercado de trabalho.
Programação e TI
Apresenta o papel do programador no desenvolvimento de sistemas, sites, aplicativos e bancos de dados, explicando suas principais responsabilidades e áreas de atuação.
Desenvolvimento de Software
Explica como ocorre o processo de desenvolvimento de um sistema, desde o levantamento de requisitos até os testes e manutenção, mostrando exemplos de projetos reais.
Desenvolvimento de Jogos
Mostra todas as etapas da criação de um jogo digital, incluindo pré-produção, produção, testes, lançamento e suporte.
Design Gráfico
Apresenta a profissão de designer gráfico, destacando a importância da criatividade na criação de identidades visuais, materiais publicitários e interfaces digitais.
Gestão de Banco de Dados
Explica como funciona a modelagem, organização e administração de bancos de dados, além das tecnologias utilizadas nessa área.
Vôlei Profissional
Apresenta a rotina de um atleta profissional de vôlei, abordando preparação física, fundamentos técnicos, estratégia e trabalho em equipe.
7. Desenvolvimento
O projeto foi desenvolvido em equipe, onde cada integrante ficou responsável pela criação e organização do conteúdo referente à profissão escolhida.
Durante o desenvolvimento foram utilizadas boas práticas de organização de arquivos, versionamento através do GitHub e divisão de tarefas para facilitar o trabalho em grupo.
Também foram aplicados conhecimentos de HTML, CSS e JavaScript para construir uma interface agradável e funcional.
8. Desafios Encontrados
Durante o desenvolvimento enfrentamos alguns desafios, como:
Organização dos arquivos do projeto.
Ajuste do layout entre diferentes páginas.
Correção dos caminhos das imagens.
Integração das páginas.
Trabalho em equipe utilizando GitHub.
Padronização do design.
Esses desafios contribuíram para o aprendizado dos integrantes e para o aprimoramento das habilidades em desenvolvimento web.
9. Resultados Obtidos
O projeto foi concluído com sucesso, apresentando uma plataforma organizada, funcional e visualmente agradável.
Além de ampliar nossos conhecimentos sobre diferentes profissões, também desenvolvemos habilidades práticas em programação, organização de projetos, trabalho em equipe e utilização de ferramentas profissionais.
10. Conclusão
O desenvolvimento do projeto Nossas Futuras Profissões proporcionou uma experiência prática na criação de um site utilizando tecnologias web.
Além do aprendizado técnico, o projeto permitiu conhecer melhor diversas áreas profissionais, compreender suas responsabilidades e perceber como diferentes carreiras podem contribuir para a sociedade.
A experiência também fortaleceu o trabalho em equipe, a resolução de problemas e a utilização de ferramentas amplamente empregadas no mercado de tecnologia, tornando o projeto uma importante etapa da nossa formação acadêmica.
